# Architecture

LaunchKit is a pnpm monorepo with TypeScript across infrastructure, backend, frontend, database, and tests.

## Runtime Flow

1. CloudFront serves the React app from a private S3 bucket.
2. The frontend reads `/config/runtime.json` for API and Cognito IDs.
3. Cognito handles sign-up and sign-in.
4. API Gateway HTTP API validates Cognito JWTs.
5. Lambda runs the Hono API.
6. Lambda reads database secrets from Secrets Manager.
7. Drizzle queries Neon Postgres.
8. File uploads use S3 presigned URLs.

## Local Flow

Local development uses:

- Vite at `localhost:5173`.
- Hono node server at `localhost:4000`.
- Docker Postgres at `localhost:5432`.
- Mock auth headers generated by the frontend.

Local mode does not require AWS until you deploy.
